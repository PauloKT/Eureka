# Eureka — Expo / React Native

Projeto independente para Android e iOS. A tela está em App.js.

## Executar

Requer Node.js 22.13 ou superior para Expo SDK 58.

1. Abra esta pasta no terminal.
2. Execute npm install.
3. Execute npm start.
4. Abra no Expo Go ou emulador.

## Integração

As descobertas estão marcadas como MOCK e usam conteúdo de demonstração. A função getDiscoveriesMock() simula uma busca assíncrona e trata erro; conecte-a à API de pesquisa quando o contrato estiver disponível. Os players simulam o progresso visualmente, sem reproduzir áudio. Não há segredos nem chamadas pagas no frontend.

O episódio só aparece depois de selecionar uma descoberta e confirmar. O histórico registra um episódio quando a pessoa inicia a reprodução e permanece na memória durante a sessão.
